¿Dónde registro el inventario?

Primero guarda el producto. Luego, desde la lista de Productos, utiliza + Lote para registrar el número de lote, vencimiento y la cantidad recibida.

El stock del producto no se escribe manualmente: se obtiene de los lotes disponibles.
